# Phase 0 — Starter App and Project Identity

## Objective

Create the minimum production-planning starter app for 3B Motors MOS.

## Completed scope

- monorepo foundation
- project identity configuration
- production status page
- root homepage
- NOT READY banner
- engineering contract
- phase list
- basic test coverage

## Explicitly out of scope

- public website
- catalog
- ecommerce
- portals
- inventory
- finance
- service
- logistics
- procurement
- integrations
- AI
- QA engine

## Acceptance criteria

- app renders
- project identity is correct
- production status is NOT READY
- business modules are not built
- tests validate identity and phase list
